# Stageclick

Setlist click app for live drumming on iPhone (Safari, wired IEM).

- Import a rehearsal recording (Voice Memos → Save to Files → **Add song**).
- BPM and downbeat are detected automatically. Adjust with ±1, ½×/2×, Tap, or beat/10 ms nudges.
- Pick a 1/2/4/8-bar groove. **Show** mode plays the groove, then keeps the click going (bar 1 accented).
- Songs are stored on the phone (IndexedDB). The screen stays awake during playback.

Live at https://shafiqabedin.github.io/stageclick/ — single file: `index.html`.
